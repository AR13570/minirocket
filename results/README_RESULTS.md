# Results index (group pruning and stratified biases)

All runs: Windows 11 (10.0.26200), AMD Ryzen 9 8940HX (32 logical CPUs), Python 3.14.7, numba 0.63.1, numpy 2.3.5, scikit-learn 1.8.0, scipy 1.17.1, aeon 1.5.0; full list in `environment_freeze.txt`. All timed runs used `NUMBA_NUM_THREADS=1` (scikit-learn BLAS threads not limited), `PYTHONWARNINGS=ignore`, and `PYTHONPATH="$PWD/code:$PWD/compat_windows"`. Code under test did not change after commit `1dabf25` (`code/minirocket_pruned.py`, `code/minirocket_stratified.py`, `experiments/group_pruning.py`, `experiments/summarise.py`); later commits only added scripts and documents. Dataset: UCR 2018 univariate archive (`data/Univariate_ts/`, not committed). Every row of every run has `equal_to_full_columns = True` (0 mismatches).
